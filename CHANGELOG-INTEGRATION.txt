Compatibility work
------------------

  including archive services, local-album imports and reading-progress handling.
- Reapply NAS catalog merging, storage indicators, lazy reading, sync actions,
  batch operations and deletion scope to the new download components.
- Bind the compact pager to the current scene adapter/recycler after view
  recreation. Keep drawer locking and quick-panel cleanup on view destruction.
- Keep the existing debug application ID so existing fork installations can be
  updated in place; append a distinct NAS integration version suffix.
- Preserve atomic thumbnail cache writes and stale-callback protection for
  asynchronously loaded archive covers; use LoadImageView's load lifecycle.
- Clear recycled reading-progress text when no reading metadata is available.
- Align the 500-item pagination boundary in the adapter and controller so the
  hidden pager cannot leave rows inaccessible; validate resolved row offsets.

Limitations and migration notes
------------------------------
- This integration did not run destructive live-NAS or multi-device sync tests.
- Cloud favorites remain on the service and require the same account; login
  cookies are not part of the official exported database.
- Opening details/reading can refresh metadata and update reading history;
  built-in quick-search name translation may also update displayed names.
- Keep an export and original APK before replacing a differently signed app.
  The device migration used uninstall-with-data-retention for rollback and did
  not delete the shared download directory.
- Device exports, screenshots, credentials, addresses and audit scripts are not
  included in this repository or the commit.
